# Campaign content audit

This file is generated by `npm run audit:campaign` from the bundled 228-page Exile-UI route and ExileQuesting's semantic annotation layer.

The audit distinguishes decisive action signals (kill, travel, reward, waypoint, trial, passive, etc.) from contextual layout/directional clues. Context-only pages are review candidates rather than automatic failures: a wall-following clue must never outrank a decisive objective in the glance-first overlay.

Run the audit after campaign-data or action-parser changes to refresh exact per-act coverage numbers.

The Focus overlay never renders raw upstream markup directly. Structured actions are generated in `src/core/actions.ts`, while source syntax remains available only for diagnostics/auditing and fallback context.
