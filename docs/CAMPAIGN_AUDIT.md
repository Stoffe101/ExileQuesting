# Campaign content audit

Audit run: 2026-09-01 against the bundled Exile-UI campaign snapshot.

The audit distinguishes decisive action signals (kill, travel, reward, waypoint, trial, passive, etc.) from contextual layout/directional clues. Context-only pages are review candidates rather than automatic failures: a wall-following clue must never outrank a decisive objective in the glance-first overlay.

## What this means

The semantic-action layer can currently identify at least one decisive action signal for every bundled route page, which means the Overlay V2 no longer needs to fall back to raw Exile-UI text as its primary Focus-mode objective.

This is **not** the same thing as claiming every one of the 228 pages has perfect hand-authored coaching. Only 19 pages currently match bespoke guidance annotations. The next content-quality pass should therefore focus on wording review, high-value warnings, layout tells, town/vendor transitions and permanent rewards rather than writing paragraphs for every route page.

## Review rule

Directional clues remain context even if they appear earlier in an upstream route page. This is deliberate. For example, `follow side of wall` must not become **NOW** when the same page later contains a decisive `kill Hailrake` objective.

Run `npm run audit:campaign` after campaign-data, annotation or action-parser changes to refresh these metrics.
